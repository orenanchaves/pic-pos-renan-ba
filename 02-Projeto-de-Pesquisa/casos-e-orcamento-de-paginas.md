## Três fragilidades conhecidas

Registradas para não serem redescobertas em outubro.

**1. A Teresa Perez não é um objeto de design digital.** Os outros três são interfaces —
têm telas, arquitetura de informação, fluxo. Ela é um serviço humano; o site é vitrine e
captação, não o produto. Nos eixos de interface, esse caso vem vazio — justamente o caso
que carrega a tese.

**2. Decolar e CVC ocupam quase a mesma posição.** Ambas intermediárias de varejo no
Brasil; a diferença é gradual, não categórica. Diferenças graduais custam páginas para
sustentar.

**3. A temporalidade declarada não tem caso.** O tema diz que o recorte acompanha "a
chegada de agentes conversacionais e de inteligência artificial ao setor" — e nenhum dos
quatro é isso. A âncora temporal fica decorativa.

### Substituição estudada, caso o feedback aponte para lá

Trocar a **CVC** por **o uso de modelos conversacionais genéricos** (ChatGPT, Gemini) para
planejamento de viagem. Ganhos: cada degrau passa a ser um paradigma de interação distinto
— busca, vitrine algorítmica, diálogo, curadoria — e a temporalidade ganha corpo.

Dois cuidados se isso for adiante:

- **Nomear como paradigma, não como marca.** "O uso de modelos conversacionais genéricos",
  não "ChatGPT". Os outros três são empresas de viagem; um LLM não é. Como paradigma, todos
  os quatro ficam no mesmo plano.
- **Registrar a interação.** Saída de LLM varia entre execuções — não é tela estável.
  Documentar prompts, data, modelo e versão, e tratar como amostra de interação registrada.
  Isso vira parágrafo de metodologia na UN 04.

## O orçamento de páginas

Página ABNT (Arial 12, entrelinha 1,5, margens 3/2 cm): **38 linhas, ~550 palavras**.

O que um artigo científico gasta **fora da análise**:

| Parte | Páginas |
|---|---|
| Capa + folha de rosto | 2,0 |
| Resumo + palavras-chave | 0,5 |
| Abstract + keywords | 0,5 |
| Sumário | 0,5 |
| Introdução | 1,5 |
| Referencial teórico | 4,0 |
| Metodologia | 1,5 |
| Considerações finais | 1,5 |
| Referências | 1,5 |
| **Subtotal** | **13,5** |

| Artigo de | Sobra para a análise |
|---|---|
| 15 páginas | **1,5 página — 827 palavras.** Não cabe |
| 20 páginas | 6,5 páginas — 3.585 palavras |

> ⚠️ **O artigo tem que mirar nas 20 páginas**, o teto do modelo. Com 15, quatro casos ficam
> com 200 palavras cada — legenda, não análise.

### O gargalo é o número de células, não de casos

| Arranjo (em 20 páginas) | Palavras por bloco |
|---|---|
| 4 casos × 4 eixos = 16 blocos | 224 — aperta |
| **4 casos × 3 eixos = 12 blocos** | **299 — confortável** |
| 3 casos × 3 eixos = 9 blocos | 398 — folgado |

**Não é preciso cortar caso. É preciso cortar um eixo.**

### Qual eixo cortar

Os quatro eixos declarados no tema: arquitetura da informação · **grau de mediação da
jornada** · carga cognitiva · linguagem de interface.

O segundo não é eixo de análise — é o **princípio que ordena o espectro**. É ele que define
a posição de cada caso na escala. Analisá-lo como variável é circular: conclui-se que o mais
mediado é o mais mediado.

Ele é a espinha do trabalho, não uma coluna da tabela.

**Eixos que ficam:** arquitetura da informação · carga cognitiva · linguagem de interface.
