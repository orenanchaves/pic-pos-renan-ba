# Estrutura do Projeto de Pesquisa

Modelo oficial: `04-Referencias/Estrutura do Projeto de Pesquisa 2025-1 (PIC PÓS).docx` (versão mais recente)
(usar como template — ele já vem com capa, folha de rosto, sumário automático e formatação ABNT)

---

## Sumário do documento

```
1  INTRODUÇÃO
   1.2  Tema do projeto
   1.3  Problema
   1.4  Objetivos
        1.4.1  Objetivo geral
        1.4.2  Objetivos específicos
   1.5  Justificativa(s)
2  REFERENCIAL TEÓRICO
3  METODOLOGIA
4  CRONOGRAMA
5  REFERÊNCIAS
```

## Mapa: unidade → seção do projeto

| Unidade | Prazo | Seção que você escreve |
|---|---|---|
| **UN 01** | 13.08 – 21.08 | `1.2 Tema do projeto` |
| **UN 02** | 22.08 – 05.09 | `1.3 Problema` + `1.4 Objetivos` (geral e específicos) + `1.5 Justificativa` |
| **UN 03** | 06.09 – 20.09 | `2 Referencial teórico` |
| **UN 04** | 21.09 – 06.10 | `3 Metodologia` + `4 Cronograma` + `5 Referências` |
| **Entrega** | 07.10 – 21.10 | Documento completo, revisado e formatado |
| **Projeto Final** | 22.10 – 27.11 | **Paper** (trabalho científico final) |

Cada unidade é um pedaço do mesmo documento. Ao final, é só costurar tudo.

> ⚠️ O template circula na versão 2024.2 — atualizar ano, curso e nome antes de entregar.

## Cronograma (seção 4)

> "O cronograma é um planejamento para a execução do trabalho, desde a escolha do tema, elaboração do projeto de pesquisa, depósito, até o depósito final. É a distribuição das atividades da pesquisa no tempo, incluindo o período da PIC Pós até o depósito do paper."

## Referências (seção 5) — modelos ABNT do template

**Livro**
```
SOBRENOME, Nome do Autor. Título do livro: subtítulo. Local de Publicação: Editora, ano.
```

**Artigo de periódico**
```
SOBRENOME, Nome do Autor. Título da matéria. Nome do Periódico, volume, número, p. X-Z, dia mês ano.
```

**Site / matéria online**
```
NOME DO SITE. Título da matéria. Disponível em: <http://endereco-completo.com.br>. Acesso em: 08 ago. 2026.
SOBRENOME, Nome do Autor. Título da matéria. Disponível em: <http://endereco-completo.com.br>. Acesso em: 01 jun. 2026.
```

Norma completa: `04-Referencias/NBR6023 - Referências.pdf`. Citações no texto: `NBR10520`.
